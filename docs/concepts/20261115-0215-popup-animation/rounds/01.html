Runde 1 · Wie Popups auf- und zugehen

Drei Bewegungen für dieselben vier Popup-Arten: ein Menü, einen Dialog, ein Großfenster und einen Hinweis. Jede Seite spielt Öffnen und Schließen in einer Schleife von 5 Sekunden ab, Klick auf die Auslöser im Mock wechselt die Art. Inhalt und Aufbau sind in allen drei Varianten gleich; wie ein Popup aufgebaut ist, klärt das zweite Concept „Popup-Aufbau“.

Fest steht: Es bewegen sich nur Lage, Größe, Deckkraft, Ausschnitt und Filter, Fokus und Escape bleiben bei scDialog, und „Bewegung reduzieren“ bekommt immer eine ruhige Fassung. Heute läuft die Kamera-Welt-Bewegung (scPopupMotion) nur an 11 Popups; die Fragen zu Tempo, Herkunft und Geltung stehen unter „Fragen“.

Neun Fragen zur Bewegung, die für jede der drei Varianten gleich gelten: wie schnell, woher und für welche Popups.

Die Varianten zeigen den Stil, hier geht es um Tempo und Regeln dahinter. Überall ist eine Empfehlung vorbelegt.

1,5 s weniger
Tempo Herkunft und Eingabe Geltung

≈ 5 min

Neun Fragen in drei Themen, jede mit einer Empfehlung.

Die Dauern stammen aus popup-motion.scss auf dem Stand von main. Im Browser gemessen ist davon nichts.

Großfenster brauchen fast 2 s zum Öffnen und 1,2 s zum Schließen.

Wer im Codex fünf Bauteile tauscht, sieht zehn Animationen. Jede Sekunde davon ist Wartezeit, weil der Inhalt erst am Ende steht.

Gilt für: alle Popups

Bis die letzte Zeile in „Bauteil tauschen“ steht, vergehen 1,96 s; wer fünf Teile tauscht, wartet so fast 10 s auf Animation.

Wie lange darf das Öffnen dauern, bis du arbeiten kannst?

Wie viel Inszenierung jede Variante überhaupt zeigen kann.

Das Großfenster braucht zweieinhalbmal so lang wie ein Menü.

Menüs und Panels liegen knapp unter einer Sekunde.

.pm-small { --pm-total: 800; }
.pm-large { --pm-total: 1960; }
.pm-panel { --pm-total: 960; }

Gilt für: alle Popups

Nach „Übernehmen“ reagiert die Seite erst 1,2 s später wieder, weil ein Großfenster beim Schließen sein Öffnen rückwärts abspielt.

Wie geht ein Popup zu?

Schließen dauert heute 60 % des Öffnens.

Auch das Apps-Menü braucht fast eine halbe Sekunde, bis es weg ist.

/** A close plays the open reversed in this share of the time. */
export const POPUP_MOTION_CLOSE_SHARE = 0.6;

Gilt für: Popups mit Listen und Tabellen

Die zehnte Zeile einer Tabelle steht erst fast 1,9 s nach dem Klick, weil Zeilen im 70-ms-Takt nacheinander kommen.

Wie kommen Zeilen und Einträge herein?

Die Kaskade beginnt erst nach einer Sekunde.

Betrifft Bauteiltausch, Komponenten-Fenster und Vergleich.

.pm-row {
  --d: calc(1000 + var(--pm-i, 0) * 70); --t: 260;
}

Woher ein Popup kommt und ab wann es Eingaben annimmt.

Menüs und Hinweise wachsen heute aus einer Ecke, Dialoge erscheinen ohne Herkunft, Großfenster steigen von unten. Die drei Varianten setzen das gleich um; die Fragen hier gelten für jede.

Gilt für: alle Popups

Ob ein Fenster zu deinem Klick gehört, zeigt die Bewegung nur bei Menüs; ein Dialog springt ohne Herkunft auf.

Woher kommt ein Popup?

Drei Popup-Arten, drei verschiedene Herkünfte.

Großfenster steigen dagegen von unten hinter einem Horizont auf.

Apps-Menü          wächst aus dem Knopf oben rechts
Bestätigen         erscheint ohne Bewegung in der Mitte
Bauteil tauschen   steigt von unten hinter einem Horizont auf

Gilt für: alle Popups mit Eingabe oder Knöpfen

Wer nach dem Öffnen sofort tippt, verliert die ersten Buchstaben, wenn ein Popup erst nach seiner Animation den Fokus bekommt.

Ab wann nimmt ein Popup Eingaben an?

Die Schnellsuche lebt davon, dass man sofort tippt.

Betrifft vor allem Schnellsuche, Bestätigen und Formulare in HQ-Dialogen.

Strg + K           Suche öffnet
„gladius“ tippen   sofort danach
Fokus sofort       → gladius
Fokus nach 300 ms  → ius

Gilt für: Menüs, Panels, Hinweise

Klickst du ein Menü zu und gleich wieder auf, springt es auf null zurück und baut sich komplett neu auf.

Was passiert bei einem schnellen zweiten Klick?

Ein Neustart setzt jede Teil-Animation auf null.

Das betrifft alles, was während des Schließens noch im Bild ist.

restart(): void {
  cl.remove('pm-out');
  cl.add('pm-in');
  this.replay(); // every layer back to 0 ms
}

11 Popups bewegen sich gemeinsam, die übrigen eigen oder gar nicht.

Gezählt aus dem Code auf dem Stand von main, die beiden unteren Zahlen gerundet.

Gilt für: alle Popup-Arten

Nur 11 von rund 35 Popups bewegen sich gemeinsam; 8 springen ohne jede Bewegung auf, 15 bringen ihre eigene mit.

Welche Popups bekommen die gemeinsame Bewegung?

Vier Wege, ein Popup zu öffnen.

Die Liste im Beispiel nennt, wer heute womit aufgeht.

gemeinsam  Apps, Konto, Merkliste, Hinweise, Bauteil tauschen, Vergleich
dlg-in     HQ-Dialoge, Wunschkorb (220 ms)
sheet-in   Overlay-Seiten (160 ms)
grow       Übergabe aufs Handy (180 ms)
keine      Bestätigen, Schnellsuche, Beta-Schalter, Admin-Menü

Gilt für: Leute mit „Bewegung reduzieren“

Wer „Bewegung reduzieren“ eingestellt hat, bekommt 160 ms Einblenden ohne Effektschichten; Größen- und Lageänderungen fallen ganz weg.

Was sehen Leute mit „Bewegung reduzieren“?

Die ruhige Fassung gibt es schon, offen ist nur ihre Form.

Gilt für jede der drei Varianten gleich.

@media (prefers-reduced-motion: reduce) {
  .pm-small.pm-in { animation: pm-fade-in 160ms linear; }
}

Gilt für: Dialoge und Großfenster auf dem Handy

Auf dem Handy liegen HQ-Dialoge schon als Blatt am unteren Rand, gleiten aber nur 8 px hoch; das Blatt wirkt, als wäre es schon dagewesen.

Wie öffnen Dialoge auf dem Handy?

Das Blatt gibt es schon, nur seine Bewegung fehlt.

Ab 640 px Breite und darunter.

@media (max-width: 640px) {
  .scrim { padding: 0; align-items: end; }
  .sheet { width: 100%; border-radius: 16px 16px 0 0; }
}
