{{iteration.tab}} 3 · Der Pfad und das Entfernen

Die Richtung „Am Wunsch“ steht. „Der Pfad“ zeigt sie mit deinen Korrekturen: Der Wunsch-Kreis behält seinen durchgezogenen Ring, nur das kleine Routen-Zeichen markiert die Zuordnung. „Entfernen“ arbeitet den einen schweren Fall durch: einen Wunsch verringern oder entfernen, der zu einer Operation gehört. „Operation“ ist nur der Arbeitstitel, bis der Name in der Analyse entschieden ist. Gemessen wird das Zuordnen weiter mit hq:path_group_assign, das Lösen über den Dialog neu mit hq:path_group_release { surface, pieces, dissolved }, sichtbar als Ablauf „Wunsch → zugeordnet → erfüllt“ im HQ-Dashboard in PostHog.
