# Round 3 brief — Karteikarten neu gedacht

## Template and purpose

- Template: **design**, `fidelity: live` (the user kept Live-Treue on) — same live-round rules as round 2:
  `data-fidelity="live"`, `data-fidelity-note`, `data-fidelity-approx` (admin view still not screenshot-able),
  live CSS by reference (reuse `assets/02/app.css` + `assets/02/star-ui-tokens.css`, or copy them to `assets/03/`
  if the gate wants one folder per round).
- **Favourite: d2 · Kartenstapel.** It is the starting point; keep its structure. d1 and d3 are out, except what is
  named below.
- The user asked verbatim on the d2 term card: **„gern nochmal varianten der karten hier, denke gut drüber nach“**.
  So round 3 shows **three designs that are three card variants** inside the same refined d2 frame
  (`data-design-set="alternatives"`, overview attributes motto / three traits / icon). Everything outside the card
  (rail menu, stats, daily goal, leaderboard, undo, bottom bar) is the SAME refined frame in all three, so the
  comparison is only about the card. Think hard about the card variants — genuinely different ideas of what one
  decision card is, e.g.:
  - **v1 · Duell-Karte**: one card, the two options as its two halves (left/right), swiping tilts toward a half;
    examples of each option printed on its half.
  - **v2 · Zwei Karten nebeneinander / Fächer**: each option is its own card in a fan; you pull one card out
    (swipe it up/out) — the stack metaphor carries through.
  - **v3 · Vorher/Nachher-Karte**: the card shows the English source and a live preview strip of the affected texts;
    tapping/swiping flips the whole strip between option A and B (you see the effect, then commit).
  The author may replace these with better ideas, but the three must differ in the card concept, not in colour.
- Viewports desktop + phone (portrait), same six screens per design as round 2: s1 Start · s2 Schreibweisen-Frage ·
  s3 Begriffs-Frage · s4 Nach der Antwort · s5 Stapel geschafft · s6 Veto-Liste. Click-through wiring as before.
