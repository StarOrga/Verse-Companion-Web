Ein workflow_dispatch auf main hat v0.84.3 gebaut, den Tag angelegt und auf den öffentlichen Mirror geladen. Danach hat der Tag-Lauf dieselbe Version neu gebaut.

Was darf ein manuell gestarteter Uploader-Build künftig?

Ob je wieder zwei Builds derselben Version mit verschiedenen Tokens erscheinen können.

Der Schritt „Resolve release tag“ prüft nur, ob der Tag schon existiert.

Beim Dispatch gab es den Tag noch nicht, also lief alles durch. Der Tag-Lauf danach baute mit neuem Token neu und überschrieb den Mirror.
