Runde 1 · Etappe A · Wo steht der Patch – und wie sieht ein Update-Fehler aus?

Drei Richtungen für Kopfzeile, Konto-Popover, Statuszeile und Update-Banner des Data Uploaders. Jede Richtung zeigt dieselben drei Zustände: Hauptfenster, offenes Popover, Update-Fehler.

Abdeckung & Bündel

Abdeckung (aus dem Sammelmodus)

  • #1 übernommen + Frage beantwortet: „warum an drei stellen patch numemrn etc. Polishe das ui nochmal in diesen titelzeilen und popup etc....“ Die drei Stellen zeigen drei verschiedene Dinge: die Kopfzeile deinen lokal installierten Spielstand („LIVE v4.10.3 (13165946)“, rechts abgeschnitten), das Popover den Stand auf dem Server („LIVE v4.10.3 · 454.632“, wobei 454.632 die Anzahl der Einträge ist, keine Build-Nummer) und die Statuszeile die Meldung des Autoruns („LIVE 4.10.3 (13165946) ist auf dem Server …“, ohne „v“). Sie sehen aber alle gleich aus.
  • #2 übernommen: „udpate fehler /“. Der 401 invalid_or_revoked_release_token kommt nicht vom Login. Am 21.11. haben zwei CI-Läufe v0.84.3 gebaut: ein workflow_dispatch um 12:53 UTC mit Token 268abf3e… und der Tag-Lauf um 13:08 UTC mit dbef63fc…. Registriert wurde nur dbef63fc. Dein Updater hat um 13:16 UTC das Setup aus dem Dispatch-Lauf geladen, die Mirror-Dateien wurden erst um 13:21 UTC ersetzt. Deshalb ist deine installierte v0.84.3 dem Update-Server unbekannt. Außerdem zeigt das Banner den rohen HttpError samt Response-Headern.

Bündel

  • B1 · Renderer (Etappe A, diese Runde): Kopf-Chip main.ts:990-1004, Popover-Chip main.ts:1038, Statuszeile main.ts:645-655 + patch-countdown.ts:73, formatIdentity in src/lib/auto-run.ts:111, Update-Banner main.ts:1219-1235 + i18n update.error. Bekommt von B2 nur noch einen Fehlercode (unknown-build | offline | server | other) und zeigt dazu einen übersetzten Text. Nebenbefund: main.ts:2111 enthält hart kodierten deutschen Text.
  • B2 · Updater, CI und Server (Etappe B, nächste Runde): Fehlerklassen in updater.ts, Schutz in data-uploader-build.yml gegen zwei Builds derselben Version, Rettung der hängenden v0.84.3-Installationen.
