## The round's designs — vary ONE sub-element: how a row shows the difference to the baseline

All three designs = round 2's d2 (same columns, same list logic, same live frame and strip). They
differ only in the row's comparison display. Same pages, same order, same `data-nav-label`:

1. `Gladius · ab Werk` — Kampf, nothing changed: what a row shows when it equals the baseline (calm).
2. `Gladius · geändert` — Kampf, the two CF-337 swapped for a stronger S3 gun (draft, unsaved): rows
   that moved show the difference (Dauer-DPS up, Energie/IR up, etc.), unchanged rows stay calm.
3. `C2 Hercules · gegen gespeichert` — Transport, a saved hangar configuration exists and the current
   draft differs from it (e.g. a shield swapped): shows the baseline is the saved version.
4. `Alle Werte offen` — page 2's state with all columns' lists continued; differences visible there
   too.

Plus, on page 1 or 2, the Einsatz picker opened showing Transport / Bergbau / Bergung disabled for
the Gladius with their reasons (one screen can show the picker open; keep page count at 4).

Where does the user see and switch the baseline? Draw ONE quiet control above the row (near the live
„Alle Werte aller vier“ switch, or as a segment in the head band) — „Vergleich: Werk | Gespeichert“ —
identical in all three designs (it is not the varied element). Read how the live page already names
the factory loadout and saved loadouts: `src/app/codex/detail/codex-loadout-draft.store.ts`,
`src/app/codex/saved-loadouts/`, `src/app/codex/holo/codex-holo-changes.component.ts` (the
„Änderungen“ tab / journal), the hero action `codex.detail.actionFactoryLoadout`, and the „Standard-
Loadout ▾“ pill in the live head band. Use the live wording where it exists.

Variants of the row's comparison display (motto, three traits, icon each; colours not accent blue):

- **d1 „Balken ab Basislinie“**: the mini bar becomes a diverging bar around a centre mark = baseline;
  it grows right for better, left for worse (better/worse per metric: lower-is-better for IR, EM,
  Querschnitt, mass…). Delta value in small text beside it („+120“). Unchanged rows: bar hidden, only
  the centre tick.
- **d2 „Wert mit Basiswert“**: no bar; the row shows current value and, when changed, the baseline
  value struck/ghosted beside it plus a delta chip (success for better, `--sc-warning` for worse —
  never `--sc-danger`, project rule: a worse comparison value is a warning, not an error).
- **d3 „Zwei Marken auf einer Spur“**: one track per row, scaled to the metric's range in the ship
  class; a hollow mark = baseline, a filled mark = current; the gap between them is the change.
  Unchanged = one mark.

Annotations: at most 3 per changed screen, ids `r3-dN-sM-aK`. Good questions: unchanged rows fully
calm vs. a faint baseline tick; delta as number vs. percent; where the baseline switch sits.
`data-design-improved` on each design (≤ 40 chars), e.g. „Vergleich zur Basis statt Rang“.
